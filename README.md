An entry for the make.fun bounty **Worst Superpower**: invent the most useless
superpower in one line of at most 140 characters.

## The entry

> I can count every grain of rice in any bowl, but only after I've already eaten it.

82 characters, one line. Counting grains of rice is pointless on its own — and
the twist kills even that: the count arrives only once the bowl is empty, so
there is nothing left to count, nobody to impress, and no problem it could
solve. A hero solemnly announcing the exact grain count of a meal that is
already gone.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes exactly
that one line to `/output/entry.txt`, with no trailing newline, after
asserting it is a single line of at most 140 characters.

```sh
python3 main.py
```
